# Интернет-магазин

## Описание проекта

Проект интернет-магазина, реализованный с использованием объектно-ориентированного подхода (ООП).

На текущем этапе реализованы:
- классы `Product` и `Category` для представления товаров и категорий;
- создание экземпляров классов с необходимыми атрибутами;
- загрузка данных из JSON-файлов;
- преобразование данных из JSON в объекты Python.

## Реализованные классы

### Product

Класс представляет товар интернет-магазина.

Основные атрибуты:
- название товара;
- описание;
- цена;
- количество.

### Category

Класс представляет категорию товаров.

Основные атрибуты:
- название категории;
- описание категории;
- список товаров.

## Дополнительно реализованы:

- подсчёт количества категорий;
- подсчёт общего количества товаров;
- добавление товаров в категорию с проверкой типа объекта;
- итерация по товарам категории.

### Smartphone

Класс-наследник `Product`, представляющий смартфон.

Дополнительные атрибуты:

- эффективность;
- модель;
- объём памяти;
- цвет.

### LawnGrass

Класс-наследник `Product`, представляющий газонную траву.

Дополнительные атрибуты:

- страна-производитель;
- период всхожести;
- цвет.

## Наследование и проверка типов

`Smartphone` и `LawnGrass` наследуются от `Product`.

Оператор `+` позволяет складывать товары только одного и того же типа. При попытке сложить объекты разных классов возникает `TypeError`.

Метод `Category.add_product()` принимает объекты класса `Product` и его наследников. При попытке добавить объект другого типа возникает `TypeError`.

## Работа с JSON

Реализована функция загрузки данных из JSON-файла:

- чтение данных из файла;
- создание объектов `Product`;
- создание объектов `Category`;
- связывание товаров с соответствующими категориями.

## Тестирование

Для проверки реализованной функциональности используются тесты `pytest`.

Тестами проверяются:

- создание объектов `Product`, `Category`, `Smartphone` и `LawnGrass`;
- работу наследования;
- сложение товаров одного типа;
- запрет сложения товаров разных типов;
- добавление товаров и наследников `Product` в категорию;
- обработку некорректных типов объектов;
- работу свойств и методов классов;
- загрузку и обработку данных.
